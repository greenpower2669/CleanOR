🧼 CleanOR V0.1 — hors ligne

Convertisseur de texte entre deux outils professionnels

Confidentialité : fonctionnement local, aucun transfert réseau. Les textes collés ne sont pas enregistrés par CleanOR. Les réglages peuvent être conservés dans ce navigateur.
Prêt. Collez un texte pour commencer.

⚙️ Paramètres de conversion

Pour du texte collé, le navigateur fournit déjà de l'Unicode. Ce choix agit uniquement sur les fichiers importés.
Le texte copié reste Unicode ; le fichier exporté est réellement encodé selon ce choix.
Cette liste est propre à chaque destination. Les caractères sont refusés un à un, sans effacer tout le texte.
Format : caractère => remplacement. Une partie droite vide supprime la séquence. Maximum 200 règles.

❓ Comment utiliser CleanOR

1. Collez votre texte dans la zone source. 2. Cliquez sur « Convertir ». 3. Cliquez sur « Copier le résultat ». Le bouton central ⇄ inverse le sens et reprend le résultat comme nouvelle entrée.

Le mode prudent remplace les caractères problématiques et conserve les accents lorsqu'ils sont acceptables. Le mode renforcé élimine les caractères non représentables. Si le système distant refuse encore le texte, ajoutez le symbole concerné dans ⚙️ Réglages.

Important : CleanOR ne connaît pas les validations internes de votre logiciel. Aucun nettoyage ne garantit l'acceptation par un serveur. Un collage de texte n'a pas de « format ANSI » imposable : l'encodage binaire n'existe que pour les fichiers importés/exportés. Une conversion avec pertes n'est pas réversible.

Vérifiez le texte avant l'enregistrement dans l'outil cible. Ne chargez pas de données professionnelles sensibles dans un dépôt GitHub public : les règles JSON ne doivent contenir que des exemples génériques.
